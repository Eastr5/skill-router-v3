# Basic Routing Examples

## Example 1: 学术研究

```
用户: 帮我找几篇关于 GNN 的论文
→ 推荐: literature-search
→ 理由: "找论文" 直接命中学术研究 → 文献搜索分支
```

## Example 2: 前端开发

```
用户: 我想搭一个 React 落地页
→ 推荐: frontend-design
→ 理由: "React" + "落地页" 命中前端 → 设计分支
```

## Example 3: 数据可视化

```
用户: 用 Python 画个图表
→ 推荐: figura
→ 理由: "画图表" 命中设计 → 出版级图表分支
```

## Example 4: 代码审查

```
用户: 帮我 review 这段代码
→ 推荐: TRAE-code-review
→ 理由: "review" 直接命中代码审查
```

## Example 5: 模糊意图

```
用户: 帮我做个东西
→ 询问: "想做什么类型的东西？1) 网站 2) 论文 3) 数据分析"
→ 理由: 意图模糊，需要澄清
```
